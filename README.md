# Final Project: Articles REST API 🚀

This is a backend web application built with **Java**, **Spring Boot**, and **Spring Data JPA** for data persistence in a **MySQL** relational database. The API provides a complete set of CRUD operations to manage an Articles inventory.

## 🎬 Video Demonstration

Watch the final result in this [video](https://youtu.be/U-SvHL3svkk)

## 🛠️ Technologies Used

* **Java 21**
* **Spring Boot 4.1.0** (Starter Web, Starter Data JPA)
* **Hibernate 7** (ORM)
* **MySQL** (Database Engine)
* **Maven** (Dependency Management)

## 📋 Prerequisites

To run this application locally, you need to have installed:
* Java JDK 21
* XAMPP (or an equivalent MySQL server)
* Postman (for testing the endpoints)

## 🔧 Local Setup & Installation

1. **Clone the repository:**
```bash
git clone https://github.com/TU_USUARIO/entrega_final_26139_MatiasFernandez.git
cd entrega_final_26139_MatiasFernandez
```

2. **Configure the Database:**
   * Open the **XAMPP Control Panel** and click **Start** on both **Apache** and **MySQL** modules.
   * Go to `http://localhost/phpmyadmin/` in your web browser.
   * Create a new, empty database named `articulos_db`.

3. **Run the Application:**
   * Open the project in your IDE (VS Code or IntelliJ).
   * Run the main class `ArticulosApplication.java`.
   * The application will automatically start listening on port `8080`. Database tables will be automatically generated by Hibernate on startup.

## 📖 API Documentation (Endpoints)

The base URL for all requests is: `http://localhost:8080/api/articulos`

| Method     | Endpoint | Description                | Request Body (JSON)    | Successful Response                 |
| :--------- | :------- | :------------------------- | :--------------------- | :---------------------------------- |
| **GET**    | `/`      | Retrieve all articles      | *None*                 | `200 OK` + JSON Array               |
| **GET**    | `/{id}`  | Find an article by ID      | *None*                 | `200 OK` + Object / `404 Not Found` |
| **POST**   | `/`      | Create a new article       | **See JSON Structure** | `200 OK` + Created Object           |
| **PUT**    | `/{id}`  | Update an existing article | **See JSON Structure** | `200 OK` + Updated Object / `404`   |
| **DELETE** | `/{id}`  | Delete an article by ID    | *None*                 | `204 No Content` / `404 Not Found`  |

### 📦 How to Test with Postman (POST / PUT)
>You can find the official Postman collection file [here](/articulos-api.postman_collection.json). Simply import it into Postman to start testing the endpoints immediately.
>
>Or either you can do it yourself 👇🏽

When creating or updating an article, follow these steps in Postman to send the data correctly:

1. Set the HTTP method to **POST** or **PUT** and enter the endpoint URL.
2. Under the URL bar, click on the **Body** tab.
3. Select the **raw** radio button.
4. On the far right dropdown, change the text format from *Text* to **JSON**.
5. Paste your data in the text area using the format below.

### 📄 JSON Structure

*Note: The `imagen` field is optional. If omitted from the payload, it will safely default to `null`.*
```json
{
  "nombre": "Teclado Mecánico RGB",
  "precio": 4500.50,
  "imagen": "https://link-de-la-imagen.com/teclado.jpg"
}
```
